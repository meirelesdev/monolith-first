# Monolith First

> Aplicacao monolitica em TypeScript com Express, Sequelize e SQLite demonstrando o padrao Monolith First antes de migrar para microservicos.

## Stack

- Express.js
- SQLite
- Sequelize ORM
- TypeScript
- Jest

## Prerequisitos

- Node.js v14+

## Como executar

```bash
# Clone o repositorio
git clone https://github.com/meirelesdev/monolith-first.git
cd monolith-first

# Instale as dependencias
npm install

# Inicie a aplicacao
npm run dev
```
